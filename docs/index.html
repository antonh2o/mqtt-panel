Политика конфиденциальности приложения MQTT+ Panel

Дата вступления в силу: 12 ноября 2026 г.
Разработчик и ответственное лицо: Тихонов Антон, antonh2o@gmail.com
Приложение: MQTT+ Panel (пакет ru.mqtt.panel) — дашборд для MQTT-брокеров, платформы narodmon.ru и Grafana.

1. Общие положения

Настоящая политика описывает, какие данные обрабатывает приложение MQTT+ Panel, с какой целью, как долго они хранятся и как их удалить. Приложение предназначено для отображения значений с датчиков и топиков, принадлежащих пользователю, и работает исключительно с серверами, которые пользователь указывает самостоятельно.

2. Какие данные обрабатываются и зачем

2.1. Учётные данные, вводимые пользователем

  • адреса, логины и пароли MQTT-брокеров пользователя;
  • логин, пароль аккаунта и API-ключ narodmon.ru;
  • адрес, логин и пароль Grafana (настройки подключения с историей графиков).

Цель: подключение к перечисленным сервисам для показа значений и истории графиков.
Хранение: только локально на устройстве, в приватном каталоге приложения (config.json).
Передача: исключительно на сами эти сервисы — брокер, api.narodmon.ru, сервер Grafana пользователя. Пароль narodmon.ru передаётся в виде необратимого хеша MD5(uuid + MD5(пароль)), не чаще одного раза в сутки.

2.2. OAuth-токен Яндекс Диска

Создаётся только по инициативе пользователя при настройке резервного копирования настроек на Яндекс Диск. Хранится локально на устройстве, передаётся только в API Яндекс Диска (oauth.yandex.ru, cloud-api.yandex.net). Используется для выгрузки/загрузки файла резервной копии настроек.

2.3. Технические данные

  • идентификатор устройства (MD5, генерируется приложением) — обязательный параметр API narodmon.ru;
  • версия приложения и название (User-Agent) — в запросе к api.github.com при проверке обновлений;
  • Client ID MQTT-подключений — генерируется приложением для связи с брокером;
  • журнал работы (mqtt-import.log: ошибки подключений, результаты опросов) — локально; отправляется разработчику только явным действием пользователя («⋮ → Отправить журнал»).

2.4. Резервная копия настроек

Файл с настройками (подключения, панели) по выбору пользователя сохраняется в файл на устройстве или на его Яндекс Диск. Копия содержит учётные данные из п. 2.1.

3. Чего приложение НЕ делает

  • не собирает статистику, аналитику и телеметрию;
  • не показывает рекламу;
  • не передаёт данные рекламным или аналитическим службам и иным третьим лицам;
  • не запрашивает доступ к контактам, геолокации, камере, микрофону, списку установленных приложений;
  • не обращается к файлам за пределами выбираемых пользователем файлов импорта/экспорта.

4. Разрешения Android, используемые приложением

РазрешениеНазначение
INTERNETсвязь с брокерами, narodmon.ru, Grafana, api.github.com, Яндекс Диск
FOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNCфоновое поддержание MQTT-подключения и опроса датчиков
POST_NOTIFICATIONSстатус-уведомление «Подключено · время» о работе фонового сервиса
REQUEST_INSTALL_PACKAGESустановка скачанного обновления по команде пользователя («⋮ → Проверить обновления»); в версиях для магазинов приложений не используется

5. Сторонние сервисы

Обработка данных аккаунтов пользователя регулируется политиками соответствующих сервисов: narodmon.ru, Яндекс, GitHub, а также MQTT-брокера и Grafana, настроенных пользователем.

6. Хранение и удаление данных

  • Сроки: данные хранятся локально, пока установлено приложение; резервная копия на Яндекс Диске — до её удаления пользователем.
  • Удаление: удаление приложения удаляет все локальные данные (настройки, пароли, журналы). Резервную копию на Яндекс Диске удалите в приложении или на Диске. Данные на стороне narodmon.ru (показания датчиков) обрабатываются по правилам платформы.
  • В любой момент можно отозвать разрешение из п. 4 в настройках Android без потери функциональности, кроме описанной у этого разрешения.
