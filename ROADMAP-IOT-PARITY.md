## Этап 1 — быстрые победы (мало кода, сразу польза)

1. **Retain в диалоге панели.** Поле `Panel.retained` есть в модели и используется при
   публикации, импортируется из конфигов IoT MQTT Panel, но чекбокса в UI нет — настройка
   недоступна. Добавить переключатель в `dialog_panel.xml` + чтение/запись в
   `DashboardActivity.readPanelForm`/`showPanelDialog`.
2. **Шаг слайдера + вертикальный слайдер.** Сейчас `stepSize = 0f` жёстко.
   Добавить `Panel.sliderStep`, поле в диалоге; вертикальная ориентация (`Panel.sliderVertical`).
3. **Множитель и десятичная точность.** `Panel.factor` (умножение значения перед показом)
   и `Panel.decimals` (округление до N знаков) — применить в `WidgetAdapter.withUnit`
   и в разборе значений.
4. **Круговая форма прогресса.** Третий вариант отображения для `PROGRESS_*`:
   кольцевая дуга вместо полосы (свой View по образцу `HorizontalProgressView`).
5. **Кнопка: payload при отпускании + повтор публикации.** `Panel.releasePayload`
   (публикуется на ACTION_UP) и `Panel.repeatIntervalMs` (повтор каждые N мс до отпускания).

## Этап 2 — новые типы панелей

6. **Шкала прибора (gauge)** — дуговой индикатор со стрелкой/заливкой и 3 цветовыми зонами
   по порогам (`firstColorEnd`, `secondColorEnd`).
7. **Гистограмма (bar graph)** — несколько топиков столбиками на одной диаграмме.
8. **Круговая/кольцевая диаграмма (pie / donut)** — несколько топиков долями.
9. **Принять текст (text input)** — поле ввода публикует произвольную строку в топик.
10. **Список (combo box) и Переключатель (radio buttons)** — публикация/подписка по
    предварительно заданному списку payload.
11. **Мульти индикатор** — состояние по списку payload (только чтение).

## Этап 3 — сетка и организация экранов

12. **Настраиваемая высота панели** (сейчас высота фиксирована по типу).
13. **Несколько дашбордов на одно подключение** с переключением + **префикс топиков**
    на дашборд (сейчас один экран = одно подключение, топики пишутся целиком).
14. **Слияние панелей** (merge left/right/top/bottom) — визуальное склеивание в блок.
15. **Блокировка панелей** (защита от случайного перетаскивания).

## Этап 4 — сеть и уведомления

16. **Уведомления по значению**: выше/ниже порога, равно, в диапазоне, вне диапазона,
    regex, совпадение строки, всегда — с текстом сообщения.
17. **Last Will and Testament** (will topic/payload/QoS/retain), **клиентские сертификаты**
    (CA / client cert / client key), выбор версии TLS, **WebSocket path** и fallback port.
18. **Уведомление при разрыве соединения**, **запуск при загрузке**, **работа в фоне**,
    **wake lock**, **фиксированная ориентация**.

## Этап 5 — экзотика

19. **Изображение** по статической ссылке или полученное через MQTT.
20. **URI Launcher** — кнопка открывает последний URL из топика.
21. **Сканер штрихкодов/QR** — скан публикует значение.
22. **Выбор цвета** — палитра публикует HEX/RGB.
23. **Выбор даты и времени** — пикер публикует дату/время.
24. **Статус сети (node status)** — online/offline payload + retain + запрос синхронизации.
25. **Дизайнер макетов** — панель-заголовок для группы объединённых панелей.
